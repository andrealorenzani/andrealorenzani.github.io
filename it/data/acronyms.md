# Glossario degli acronimi (versione italiana)
# Formato: SIGLA: significato completo
# Una per riga. Le righe che iniziano con # sono commenti e vengono ignorate.
# Il confronto è sensibile alle maiuscole e riguarda solo parole intere —
# le sigle restano scritte come compaiono davvero nel testo (spesso in
# inglese, perché è così che si usano anche in italiano nel lavoro tech).

BF: Black Friday

SLA: Accordo sul Livello di Servizio (Service Level Agreement)
DLQ: Coda dei messaggi falliti (Dead Letter Queue)
POC: Prova di Concetto (Proof of Concept)
API: Interfaccia di Programmazione delle Applicazioni (Application Programming Interface)
AWS: Amazon Web Services
SES: Simple Email Service (servizio email di AWS)
AI: Intelligenza Artificiale
ML: Apprendimento Automatico (Machine Learning)
SRE: Ingegneria dell'Affidabilità dei Sistemi (Site Reliability Engineering)
QA: Controllo Qualità (Quality Assurance)
PM: Product Manager
DM: Delivery Manager
